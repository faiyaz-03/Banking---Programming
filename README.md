🏦 ATM Banking System

📌 About the Project

The ATM Banking System is a simple console-based banking application developed using Java. It simulates basic ATM operations through a menu-driven interface, allowing users to manage their account balance and perform common banking transactions.

This project was created to practice Java programming fundamentals and develop problem-solving skills.

✨ Features

💰 Check Balance: View the current account balance.

💵 Deposit Money: Add money to the account.

🏧 Withdraw Money: Withdraw money if sufficient funds are available.

📋 Menu-Driven Interface: Select different banking operations through a simple menu.

🔄 Continuous Transactions: Perform multiple operations until choosing to exit.

🛠️ Technologies Used

Language: Java

IDE: Any Java-supported IDE or text editor

JDK: Java Development Kit

🚀 How to Run

Clone this repository:

git clone YOUR_REPOSITORY_URL

Open the project folder.

Compile the Java file:

javac Main.java

Run the program:

java Main

Replace Main.java with your actual Java filename if it is different.

🎮 How to Use

Run the program.

Choose an option from the ATM menu.

Check your balance, deposit money, or withdraw money.

Follow the on-screen instructions.

Select the exit option when you finish.

📚 Learning Objectives

Understanding Java variables and data types.

Practicing if-else and switch statements.

Using loops for repeated operations.

Handling user input with the Scanner class.

Implementing basic banking logic and input validation.
